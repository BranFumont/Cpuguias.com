# Arquitectura Básica del Procesador

## Descripción
Esta página web presenta una explicación sencilla de la arquitectura básica de un procesador (CPU). La información está organizada en pasos desplegables para facilitar la lectura y comprensión de cada componente.

## Contenido
- ¿Qué es un Procesador?
- Unidad de Control (UC)
- Unidad Aritmético-Lógica (ALU)
- Registros
- Memoria Caché
- Buses del Procesador
- Funcionamiento General

## Tecnologías Utilizadas
- HTML5
- CSS3

## Uso
1. Abrir el archivo `index.html` en un navegador web.
2. Hacer clic sobre cualquier paso para desplegar la información completa.
3. Volver a hacer clic para ocultar el contenido.

## Objetivo
Brindar una explicación clara y organizada sobre los componentes principales de una CPU y cómo trabajan en conjunto para ejecutar instrucciones.
